# Breast Cancer Detection

Classify tumors as benign or malignant using the Wisconsin breast cancer dataset built into scikit-learn.

## What is included

- A starter tabular classification pipeline
- Built-in dataset loading with no external CSV required
- Feature importance output from model coefficients

## Quick start

```bash
pip install -r requirements.txt
python src/train.py
```

The script saves the trained pipeline to `artifacts/breast_cancer_model.joblib`.
